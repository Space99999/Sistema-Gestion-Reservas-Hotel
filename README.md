# Sistema de Gestión de Reservas de Hotel

## Descripción
Este proyecto es un sistema de gestión para un hotel. Permite gestionar habitaciones, realizar y listar reservaciones, gestionar clientes, generar facturas y listar las facturas. Está implementado en Java y utiliza archivos de texto para almacenar los datos de las habitaciones, clientes, reservaciones y facturas.
SOLO ES POR CONSOLA SIN INTERFAZ GRAFICA

## Funcionalidades

- **Administrar Habitaciones**: El sistema permite agregar, modificar, eliminar y visualizar habitaciones del hotel.
- **Reservar Habitaciones**: Permite a los usuarios realizar reservaciones para habitaciones disponibles.
- **Listar Reservaciones**: Muestra todas las reservaciones realizadas en el sistema.
- **Listar Clientes**: Muestra la lista de clientes registrados en el sistema.
- **Generar Facturas**: El sistema permite generar facturas para las reservaciones realizadas, incluyendo la temporada, cantidad de días hospedados, y cálculos de IVA.
- **Listar Facturas**: Muestra todas las facturas generadas por el sistema.

## Requisitos

- Java 17 o superior.
- Maven 3.8.7
- Archivos de texto (`habitaciones.txt`, `Reservaciones.txt`, `Clientes.txt`, `Factura.txt`) para almacenar los datos.
